Votre carnet de rencontres.

Commencer

  1. Ajoutez un prénom ou un pseudo.
  2. Choisissez « Nouvelle rencontre », la date et, si vous le souhaitez, votre rang spontané avant la notation.
  3. Parcourez les dix critères. Pour chaque indicateur : 0, 0,5, 1 ou Non observé. Les choix sont enregistrés immédiatement sur cet appareil.
  4. À la fin, ajoutez vos impressions positives et négatives, puis ouvrez le résultat.
  5. Pour une rencontre ultérieure, créez une nouvelle rencontre dans la même fiche.

Vous pouvez revenir sur une rencontre dans l’historique pour compléter ses notes. Le carnet accepte plus de 30 personnes et plus de 10 rencontres par personne.

Comprendre les calculs

Chaque critère vaut la moyenne de ses indicateurs observés × 10. Exemple : 1 + 1 + 0,5 + 0,5 sur quatre observations donne 7,5/10. Les six autres indicateurs sont exclus.

Le score /100 est la moyenne pondérée des critères observés × 10. Un critère entièrement non observé n’entre pas dans le dénominateur. Sans aucune observation ou sans poids actif positif, il n’y a pas de score.

Le classement utilise la dernière rencontre avec un score, dans l’ordre de création R1, R2… La date est informative : saisissez les rencontres dans l’ordre chronologique. Les ex æquo partagent leur rang. L’évolution compare les deux dernières rencontres notées. Le classement et les catégories utilisent les valeurs exactes, avant arrondi d’affichage.

La couverture est le pourcentage d’indicateurs renseignés. Elle décrit la quantité d’observations, pas une fiabilité statistique. La comparaison peut changer si les critères observés diffèrent d’une rencontre à l’autre.

L’écart de rang est « rang spontané − rang calculé ». Positif : le calcul place mieux la personne. Les poids et les seuils sont modifiables dans Réglages et recalculent toutes les rencontres.

Les cinq catégories proposées sont : moins de 40 Peu d’affinités, de 40 à moins de 60 Neutre, de 60 à moins de 75 À suivre, de 75 à moins de 85 Très intéressant, à partir de 85 Top.

Installer et utiliser hors connexion

Ouvrez l’adresse HTTPS de l’application sur votre téléphone avec une connexion Internet. Attendez le chargement complet, puis ouvrez Réglages pour vérifier que le mode hors connexion est installé.

  • iPhone : Safari → Partager → Sur l’écran d’accueil.
  • Android : Chrome → menu ⋮ → Ajouter à l’écran d’accueil / Installer.

Ouvrez ensuite l’icône, faites une première ouverture connectée puis testez en mode avion. Les fichiers locaux ouverts par double-clic ne permettent pas l’installation complète d’une PWA : il faut une adresse HTTPS ou localhost sur ordinateur.

Sauvegardes et confidentialité

Réglages → Exporter une sauvegarde produit un fichier JSON. Conservez-le dans un endroit privé, hors du navigateur. Importer une sauvegarde remplace le carnet après confirmation et validation du fichier ; une copie du carnet actuel est téléchargée avant remplacement.

Les données restent dans le navigateur de cet appareil. Aucun serveur ne reçoit vos notes. Il n’y a ni synchronisation automatique, ni récupération de compte, ni chiffrement du fichier de sauvegarde. Une suppression des données du navigateur peut effacer le carnet. Utilisez un seul onglet à la fois et exportez régulièrement.

Excel et PWA sont indépendants : les sauvegardes JSON concernent la PWA. Elles n’importent pas le classeur Excel.

Coût de fonctionnement

L’application n’utilise aucune API payante, abonnement logiciel, base de données distante ou nom de domaine acheté. Son code complet est fourni et peut être hébergé sur une offre gratuite. Les conditions d’un hébergeur peuvent évoluer ; aucune souscription payante n’est nécessaire au fonctionnement de ce code.

Pour une adresse indépendante gratuite : créez un compte GitHub Free, puis un dépôt public ; déposez uniquement les fichiers du dossier pwa à la racine du dépôt. Dans Settings → Pages, choisissez Deploy from a branch, branche main, dossier / (root), puis Save. Ouvrez l’adresse HTTPS affichée. Le code et la grille deviennent publics ; ne déposez jamais vos sauvegardes ou votre classeur rempli dans ce dépôt.
